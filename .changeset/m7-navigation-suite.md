Navigation suite scaffold (M7, COMPONENT_SPEC §16; Compose `NavigationSuiteScaffold`, `NavigationSuiteScaffoldLayout`, `NavigationSuite`, `NavigationSuiteScaffoldState`): one set of destinations shown as the navigation the window size class calls for — a short navigation bar below 600px (horizontal items at compact height), a collapsed wide navigation rail from 600px and, by default, the expanded wide navigation rail from 1200px (m3.material.io guidance; Compose keeps the collapsed rail) — with the content beside or above it. Switching on resize keeps the selection, the item elements (bar ↔ rail share one `<nav>`, as Compose's `movableContentOf` keeps its items) and keyboard focus. Override with a fixed type (`layout-type` / `layoutType`, incl. `navigation-drawer` and `none`), `expanded-from` / `expandedFrom` (`none` / `null`: Compose's own rule), `expanded-type` / `expandedType` (a permanent drawer at large widths) or a function of the window size class. Show / hide animates on Compose's spring(0.9, 700) with its state semantics. New `components/navigation-suite-defaults.css` tokens (scaffold colors, primary action alignment / padding, the show / hide spring), m3e-css `navigation-suite.css` (`.m3e-navigation-suite` with `--bar`, `--rail`, `--drawer`, `--none`, `--navigation-hidden`, `--primary-action-start` / `--primary-action-center`, `--adaptive` for a no-JavaScript fallback, `__content`, `__primary-action`), m3e-motion `NavigationSuiteScaffoldAnimation`, `navigationSuiteOffset`, `isNavigationBarType`, `NAVIGATION_SUITE_TYPES`, `NAVIGATION_SUITE_EXPANDED_FROM` and the `expandedFrom` / `expandedType` options of `navigationSuiteType` (whose type now includes the expanded rail, the drawer and `none`), m3e-elements `<m3e-navigation-suite>` plus the `navigation-suite-layout.js` (NavigationSuiteLayout) entry, and m3e-react `<NavigationSuiteScaffold items selectedKey onSelectionChange layoutType navigationSuiteType expandedFrom expandedType isNavigationHidden primaryAction>`. React `<NavigationDrawer>` destinations gain `isDisabled` (the element already rendered disabled items).
