# DECISIONS.md — m3exp-web

Standing decisions. Do not re-litigate in Claude Code sessions; open a new entry if one must change.

| # | Decision | Date | Rationale / notes |
|---|---|---|---|
| D0 | Library name **m3exp-web**. Umbrella npm package `@kyralabs/m3exp-web`; repo `github.com/kyralabs/m3exp-web`. Layer packages keep their names: `@kyralabs/m3e-tokens`, `@kyralabs/m3e-css`, `@kyralabs/m3e-elements`, `@kyralabs/m3e-react`, internal `@kyralabs/m3e-motion`, `@kyralabs/m3e-shapes`, `@kyralabs/m3e-codegen`. | 2026-10-11 | Name chosen by owner. |
| D1 | Default font **Google Sans Flex**, self-hosted (woff2 shipped in `m3e-tokens/fonts`). Typescale maps to its variable axes; emphasized styles use weight plus other axes where useful. Axis list, ranges and license are `TODO(verify)` against google/fonts METADATA.pb before token generation. | 2026-10-11 | Matches the typeface M3 Expressive uses on Android. |
| D2 | Performance budgets as proposed in REQUIREMENTS §8 (tokens ≤12 KB, css ≤45 KB, elements ≤30 KB, shapes ≤14 KB, react ≤60 KB). | 2026-10-11 | Revisit after M4 with real numbers. |
| D3 | Color `specVersion` default = the latest MCU 0.4.0 ships (2025, or 2026 if present in the npm build — `TODO(verify)`). Older versions remain selectable. | 2026-10-11 | |
| D4 | Deprecated components (BottomAppBar, legacy Segmented Button, small FAB, legacy NavigationBar/Rail, non-expressive ListItem) are **included**, marked `@deprecated`, removed in 2.0. | 2026-10-11 | Migration path for existing apps. |
| D5 | **Material Symbols bundled** as the variable font (Apache 2.0), FILL/wght/GRAD/opsz axes exposed on `<Icon>`. A subsetting CLI (`m3e-icons subset`) ships so apps only pay for the glyphs they use. | 2026-10-11 | Full variable file is several MB. |
| D6 | **Client-side rendering only** in v1. No SSR/RSC guarantees. | 2026-10-11 | Astro static + CSR React covers all Kyra Labs consumers. |
| D7 | `m3e-elements` are **zero-dependency custom elements** (no Lit). A ≤1 KB internal base class handles attribute reflection and lifecycle. | 2026-10-11 | Elements layer is small and behavior-only; avoids a runtime dependency on every Astro page. Trade-off: more boilerplate. |
| D8 | **Side sheets are built.** Fidelity reference is m3.material.io only (no Compose Material3 component exists). | 2026-10-11 | |
| D9 | Licensing: Apache 2.0 for the repo. Ported files keep Google's original header plus a line `Ported to TypeScript by Kyra Labs from <path>@<commit>`. A `NOTICE` file lists each ported project (AndroidX Compose Material3 tokens, AndroidX graphics-shapes, material-color-utilities) with "Copyright (C) The Android Open Source Project" and the Apache 2.0 reference. Bundled fonts keep their own license files alongside (Material Symbols: Apache 2.0; Google Sans Flex: `TODO(verify)`). Not legal advice. | 2026-10-11 | Standard Apache 2.0 practice. |
| D10 | **Proposed — amends D9.** `NOTICE` gives each ported project the copyright line from its own source headers: AndroidX Compose Material3 and AndroidX graphics-shapes → "Copyright (C) The Android Open Source Project"; material-color-utilities → "Copyright 2021 Google LLC". Everything else in D9 stands. Not legal advice. | 2026-10-11 | D9 used the AOSP line for all three projects, but the MCU 0.4.0 npm sources carry `@license Copyright 2021 Google LLC` (e.g. `blend/blend.js` L3). AndroidX headers verified at `19991f2c` (`Morph.kt` L2, `MotionScheme.kt` L2). |
| D11 | **Clarifies D1.** Default `@kyralabs/m3e-tokens/fonts.css` ships Google Sans Flex with **wght + opsz** variable and wdth/ROND/slnt instanced at their fvar defaults (latin ≈ 139 KB); `fonts-full.css` ships every axis (latin ≈ 1 MB) for apps that use width, roundness or slant. Emphasized type is weight-only: GSF 5.000 has no GRAD axis and no source at the pin uses ROND/wdth for emphasized styles. | 2026-10-11 | Owner choice in the M2 fonts PR. The five-axis font is ~1 MB for Latin alone; the typescale tokens use only weight (and opsz via `font-optical-sizing: auto`). |
| D12 | **Default Material Symbols style: Rounded** (project brand choice). `@kyralabs/m3e-tokens/material-symbols.css` and `m3e-icons subset` default to Rounded; Outlined and Sharp ship as separate entries. | 2026-10-11 | No M3/M3E source names a default style (m3.material.io /styles/icons treats Outlined, Rounded and Sharp as brand choices); Google tooling (fonts.google.com/icons, Google Fonts docs, material-design-icons README, Material Web 2.5.0) defaults to Outlined. Owner chose Rounded, as REQUIREMENTS §10 already stated, to pair with Google Sans Flex. |
| D13 | **Proposed — amends D2.** The `<m3e-loading-indicator>` element entry is budgeted at the m3e-shapes budget, **≤ 14 KB** (min+brotli, bundled m3e-shapes + m3e-motion included), instead of REQUIREMENTS §8's per-element 8 KB. Every other element keeps 8 KB; m3e-elements (all) stays ≤ 30 KB. | 2026-10-12 | COMPONENT_SPEC §7 has the element morph Compose's shapes at runtime ("SVG path morph via m3e-shapes"), and D7 makes it bundle m3e-shapes, which D2 alone budgets at 14 KB. The graphics-shapes core a `Morph` needs (RoundedPolygon, Cubic, PolygonMeasure, feature mapping) is ~23 KB minified; precomputed morph data for the default sequences would be larger than the code. Measured in the M4 loading indicator PR: element entry 11.84 KB, m3e-elements (all) 12.48 KB, m3e-shapes 9.64 KB. To be re-measured with the other budgets at the end of M4 (D2). |
| D14 | **Proposed — confirms D2 and D13 after M4.** Every budget stays as written (min+brotli; size-limit units, 1 kB = 1,000 B): m3e-tokens ≤ 12 kB; m3e-css (all) ≤ 45 kB, per-component entries at their `.size-limit.json` limits (≤ 4 kB; divider 1 kB, top app bar 2 kB, legacy nav bar + rail 6 kB together); m3e-elements (all) ≤ 30 kB, per-element ≤ 8 kB except the `<m3e-loading-indicator>` entry at ≤ 14 kB (D13 confirmed); m3e-shapes ≤ 14 kB; m3e-react ≤ 60 kB. Fonts stay reported in CI, not failed. Next re-measure in M11 (1.0 hardening), or earlier in any PR that takes an entry past 90 % of its budget. m3e-react is tree-shakeable per component (REQUIREMENTS §8) since kyra-labs/m3exp-web#28, which adds single-import size-limit guards (`{ Icon }` ≤ 1 kB, `{ Button }` ≤ 16 kB, `{ LoadingIndicator }` ≤ 14 kB); the m3e-react budget does not change. | 2026-10-13 | Measured on main `e9c3167` (all M4 components) with `npx size-limit` and `node tools/report-fonts.js`. **JS/CSS:** m3e-tokens 4.32 kB (36 %); m3e-css (all) 6.99 kB (16 %), largest per-component entry button 1.77 kB, primitives 1.53 kB, legacy nav bar + rail 2.97 kB of 6 kB; m3e-elements (all) 13.34 kB (44 %), loading-indicator entry 11.84 kB (85 %), icon entry 1.23 kB, top-app-bar entry 2.2 kB of 3 kB, M3eElement base 820 B of 1 kB; m3e-shapes 9.64 kB (69 %); m3e-react 26.88 kB (45 %). **Why not tighten:** M4 ships about 10 of the ~40 COMPONENT_SPEC components, and most of the remaining ones add CSS and React Aria hooks, so cutting totals now would fail later milestones on the growth D2 was sized for. Element entries other than the loading indicator use ≤ 2.2 kB, so the 8 kB per-element cap leaves room for the behavior-only elements still to come. **Tree-shaking:** at `e9c3167`, importing only `Icon` (or any single component) from m3e-react cost 26.7 kB, the same as the whole package, because the single-file dist kept top-level `forwardRef(…)` calls without `/* @__PURE__ */` and m3e-shapes' module-level constants (e.g. `new CornerRounding(…)`), which bundlers must assume have side effects. #28 annotates them: `{ Icon }` 302 B, `{ Button }` 12.91 kB, `{ LoadingIndicator }` 11.09 kB. **Fonts (KiB):** Google Sans Flex 5.000 `fonts.css` latin 138.8, all chunks 328.5; `fonts-full.css` latin 1020.8, all chunks 2026.8; Material Symbols 2.975 full fonts: Rounded 5271.2, Outlined 3907.5, Sharp 3449.5 (apps ship an `m3e-icons subset`). |
