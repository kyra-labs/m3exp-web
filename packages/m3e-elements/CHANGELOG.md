### Minor Changes

- bb0795e: Checkbox (M8, COMPONENT_SPEC §22; Compose `Checkbox` and `TriStateCheckbox`): a native `<input type="checkbox">` in a 48dp target with an 18dp box, checked, unchecked and indeterminate, error (`aria-invalid`) and disabled. - b83f3b5: Chips (M8, COMPONENT_SPEC §18; Compose `FilterChip`, `ElevatedFilterChip`, `InputChip`, `SuggestionChip`, `ElevatedSuggestionChip`): filter, input and suggestion chips on a chip base shared with the assist chip (`.m3e-assist-chip` and `<AssistChip>` are unchanged). Suggestion chips are buttons or links (`.m3e-suggestion-chip`, `--elevated`). `--expressive` opts into Compose's `shapes` overload: ChipsTokens corners (12dp, full when selected, 8dp while pressed) morphing on the fast spatial spring, tonal colors and 4dp spacing next to icons. `.m3e-chip-set` lays chips out in 48dp rows (`--single-line`: one scrolling row). - 13d42fe: Radio button (M8, COMPONENT_SPEC §23; Compose `RadioButton`): native `<input type="radio">`s in a 48dp target with a 20dp ring, selected, unselected and disabled, grouped in a `role="radiogroup"` (or a `fieldset`) so arrow keys move the selection with no JavaScript. New `components/radio-button-defaults.css` tokens (the `RadioButton.kt` values Compose renders and the `RadioGroupSample` rows), m3e-css `radio-button.css` (`.m3e-radio-group` with an optional `--horizontal` modifier, `.m3e-radio-button` with `__input`, `__icon`, `__state`, `__label`; added to the state-layer / focus-ring lists and the `ripple.js` triggers, Space only) and m3e-react `<RadioGroup value defaultValue onChange orientation isDisabled isReadOnly isRequired name>` with `<Radio value isDisabled>`. - 1c7b296: Slider (M8, COMPONENT_SPEC §25; Compose `Slider`, `VerticalSlider`, `RangeSlider` and `SliderDefaults.CenteredTrack`): standard, range (two thumbs that meet but never cross), centered and vertical (minimum at the bottom) sliders, continuous or with stops (ticks), in sizes XS (default), S, M, L and XL from the m3.material.io token DB, with an inset icon on M–XL standard sliders, end stop indicators and a value indicator while dragged or keyboard focused; pressing, dragging or keyboard focus halves the handle at once.
